# PageHeader

L'en-tête de page ouvre chaque écran d'un parcours : un bandeau pétrole qui dit où l'on est et ce qu'on y fait.

## Classes

- `cx-pagehead` : le bandeau, fond `primary`, texte `on-primary`.
- `cx-pagehead__inner` : la colonne centrée (880 px max).
- `cx-pagehead__back` : le lien de retour (« ← Mes projets »).
- `cx-pagehead__eyebrow` : le contexte en petites capitales (nom du client, nom de l'outil).
- `cx-pagehead__title` : le titre `display`, un seul par écran.
- `cx-pagehead__lead` : une phrase qui dit ce que l'utilisateur fait sur l'écran.
- `cx-page` : le contenu qui suit ; placé juste après l'en-tête, il le chevauche de 44 px pour poser le stepper sur le bandeau.

## Ce que fournit l'intégrateur

- Le titre de l'étape, formulé pour l'utilisateur (« Votre contexte métier »).
- Une phrase d'introduction, deux au plus.
- Le nom du client dans l'eyebrow.

## Règles

- Pas de bouton dans l'en-tête : l'action principale est dans la barre d'action.
- Pas de statistique ni de date dans l'en-tête.
