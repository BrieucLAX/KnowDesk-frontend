# Badge

Le badge donne en un coup d'œil le statut, le type ou une mise en avant d'un élément. Il n'est jamais cliquable.

## Variantes

| Classe | Usage dans la base de connaissance |
|---|---|
| `cx-badge--success` | Article validé, publié. |
| `cx-badge--warning` | Revue proche, point à vérifier. |
| `cx-badge--danger` | Revue en retard, erreur signalée. |
| `cx-badge--info` | En relecture, en cours. |
| `cx-badge--neutral` | Brouillon, archivé, état sans enjeu. |
| `cx-badge--primary` | Type d'article (procédure, règle…), catégorie. |
| `cx-badge--accent` | « Nouveau », seule mise en avant chaleureuse. |

## Ce que fournit l'intégrateur

- Un libellé court, un ou deux mots.
- Pour les statuts (success, warning, danger) : une icône de 14 px avant le mot, pour ne pas dépendre de la couleur seule.

## Règles

- Un statut se lit toujours avec un mot, jamais avec une pastille de couleur seule.
- Pas plus de deux badges côte à côte sur un même élément.
