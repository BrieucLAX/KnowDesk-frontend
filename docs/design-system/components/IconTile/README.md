# IconTile

La pastille d'icône identifie une rubrique d'un formulaire ou d'une page et montre son statut d'un coup d'œil.

## Classes

- `cx-icontile` : pastille de 48 px, arrondi 14 px, icône de 24 px, fond `primary-soft`.
- `cx-icontile--done` : rubrique validée, fond `success-soft`.
- `cx-icontile--current` : rubrique à traiter maintenant, fond `primary` plein.
- `cx-icontile--optional` : rubrique facultative, fond `surface`.

## Ce que fournit l'intégrateur

- Une icône Lucide qui dit le sujet de la rubrique (voir le groupe Icons).
- Le statut en toutes lettres à côté (badge ou mention « À valider »), la pastille ne suffit pas.

## Règles

- Une pastille par rubrique, placée avant le titre.
- La même rubrique garde la même icône partout.
